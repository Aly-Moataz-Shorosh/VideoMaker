# Aly's current manual editing flow

1. DaVinci Resolve: "ripple delete silence" to remove silences. He likes it a lot — keep it unless a
   script does it equally well.
2. Premiere Pro: remove speaking MISTAKES and RETAKES (repeated sentences). (NOT silences again.)
   → Biggest candidate for automation: Claude reads the numbered transcript and marks bad sentences.
3. Premiere Pro: montage — B-roll, side pictures, side videos, motion graphics.
4. Motion is made one of three ways: After Effects, green-screen stock videos, or AI-generated.

What he wants: automate as much as possible, smart flow, high quality, free, minimum tokens, able to
produce large quantities. Manual steps are OK if the rest is automated.
